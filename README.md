# Stock Portfolio Tracker

## Project Description

The Stock Portfolio Tracker is a Python project that helps users calculate the total value of their stock portfolio. Users can enter stock names and the number of shares they own, and the program calculates the portfolio value using predefined stock prices.

## Technologies Used

- Python
- Dictionaries
- Loops
- User Input
- Arithmetic Operations

## Features Offered

- Accepts stock names from the user
- Accepts quantity of shares
- Calculates individual stock values
- Calculates total portfolio value
- Displays portfolio summary

## How to Run

1. Open the project in VS Code.
2. Run the Python file.
3. Enter stock names and quantities when prompted.
4. View the calculated portfolio value.

## Learning Outcomes

- Understanding Python dictionaries
- Working with user input
- Using loops and conditions
- Performing basic calculations
